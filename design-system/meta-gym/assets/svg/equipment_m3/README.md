# Realleader M3 — bộ icon thiết bị

8 SVG tự vẽ dựa trên hình dáng máy tại https://realleadergym.com/m3-series-p2.html (tham chiếu ngày 27/11/2026). Không nhúng ảnh sản phẩm hoặc logo vào SVG.

Dùng cùng họ Soft-Line Duotone: nền trong suốt, viewBox 48×48, nét trắng #E8EDF5 / 2.2px, đệm máy phủ gradient cam .03 → .28, chi tiết hoạt động #FF5E36. Dùng trên nền graphite; gallery chế độ sáng vẫn giữ nền tối phía sau icon. Mỗi tệp dưới 1.8 KB, ID gradient riêng, không CSS/script/font/ảnh bên ngoài. Có thể dùng bằng flutter_svg sau khi đăng ký asset trong ứng dụng.

`catalog.json` lưu đường dẫn, tên tiếng Việt, mã model và link sản phẩm. Hai mẫu 1022 và 1023 giữ tên Glute Machine của hãng, phân biệt bằng model và dáng khung; không suy diễn chúng thành hai chức năng khác khi chưa có thông số xác nhận.
