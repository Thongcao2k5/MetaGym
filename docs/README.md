# Tài liệu Meta Gym

- `requirements/`: đặc tả yêu cầu và use case.
- `architecture/`: sơ đồ và quyết định kiến trúc.

Tài liệu hiện có:

- `requirements/confirmed-workflows.md`: phạm vi, vai trò, luồng nghiệp vụ, màn hình, dữ liệu, API và tiêu chí hoàn thành MVP.
- `requirements/page-map.md`: sitemap, route, bottom navigation/sidebar và quy tắc truy cập cho Member, Coach và Admin.
- `requirements/api-contract.md`: danh sách endpoint REST theo module, phân quyền và quy tắc nghiệp vụ bắt buộc.
- `requirements/database-spec.md`: đặc tả 33 bảng PostgreSQL, cột, kiểu dữ liệu, constraint, index, quan hệ và transaction.
- `../tasks/plan.md`: kế hoạch triển khai 8 tuần, phân công và rủi ro.
- `../tasks/todo.md`: 24 task triển khai theo thứ tự phụ thuộc và các checkpoint kiểm thử.
